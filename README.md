# eBlood_api

This repository contains the backend API for the eBlood application. It manages blood donation requests, donor information, and blood bank operations.

## Setup

To set up the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/eBlood_api.git
   cd eBlood_api
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Database setup:**
   Configure your database settings in `config.py` and run migrations:
   ```bash
   python manage.py migrate
   ```

4. **Run the application:**
   ```bash
   python manage.py runserver
   ```
